# 🚀 Оценка влияния форм заряда твердого ракетного топлива и сопла ракетного двигателя твердого топлива на внутрибаллистические характеристики ракетного двигателя твердого топлива

[![Python 3.10+](https://img.shields.io/badge/Python-3.10%2B-blue.svg)](https://www.python.org/downloads/release/python-3100/)
[![Jupyter Notebook](https://img.shields.io/badge/Jupyter-Notebook-orange.svg)](https://jupyter.org/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)


В данной работе исследуется влияние геометрии заряда твердого ракетного топлива (ТРТ) и сопла на внутрибаллистические характеристики ракетного двигателя твердого топлива (РДТТ), таких как полный и удельный импульс, время горения и максимальное давление, для ряда ракетных систем (С-5, С-8, С-13, «Ураган», «Смерч», Х-15).

### **Математическая модель**

#### 1. **Геометрия заряда ТРТ и сопла**
- Рассмотрена геометрия заряда с каналом звездообразного сечения (7 лучей).
- Определены ключевые параметры: диаметр камеры сгорания (`D_кс`), минимальная толщина свода (`e_0`), радиус скругления (`r`), длина заряда (`l_зар`).
- Получены зависимости для площади поверхности горения `S(e)` и параметра Победоносцева `κ(e)` для трех стадий горения (выгорание выступов, горение по цилиндрическим поверхностям, догорание дегрессивных остатков).

#### 2. **Воспламенительный состав**
- В качестве воспламенителя рассматривается состав MTV (58% Mg, 38% C₂F₄, 4% Viton).
- Моделируется горение двояковыпуклой таблетки.
- Проведена оптимизация массы (`ω_в`) и толщины свода (`e_в`) воспламенителя по критерию минимизации отношения `p_max / p_ном` и времени воспламенения.

#### 3. **Прямая задача внутренней баллистики**
- Решается система дифференциальных уравнений, описывающая изменение давления `p(t)`, температуры `T(t)`, свободного объёма `W(t)` и других параметров.
- Учитывается эрозионное горение, теплообмен и изменение площади поверхности горения.
- Интегрирование проводится методом Рунге-Кутты 4-го порядка.

#### 2. **Инженерные формулы**
На основе регрессионного анализа 63 численных экспериментов получены следующие зависимости (R² > 0.99):

**Для полного импульса `I_p` (кН·с):**

I_p = 4122.095 · D_n^2.9927 · p_nom^0.0648 · bar_e_0^0.2479

**Для удельного импульса `I_ud` (м/с):**

I_ud = 744.002 · D_n^0.0020 · p_nom^0.0739 · bar_e_0^0.0031

**Для времени горения `t_osn` (с):**

t_osn = 22826.325 · D_n^1.0003 · p_nom^-0.3950 · bar_e_0^0.9956

где:
- `D_n` — калибр (диаметр) двигателя, м;
- `p_nom` — номинальное давление в камере сгорания, Па;
- `bar_e_0` — безразмерная толщина свода заряда.
